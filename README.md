# 🚦 Smart City Traffic Congestion Predictor

## Project Overview
The Smart City Traffic Congestion Predictor is a Machine Learning project designed to predict traffic congestion using traffic volume, average vehicle speed, weather conditions, time, and road information.

## Objectives
- Predict traffic congestion levels.
- Analyze traffic patterns.
- Understand the relationship between weather and traffic.
- Support smarter urban traffic management.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Machine Learning Algorithm
Random Forest Regressor.

## Project Features
1. Data preprocessing.
2. Exploratory Data Analysis.
3. Machine Learning model training.
4. Traffic congestion prediction.
5. Interactive web application.

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Train the model:

```bash
python model.py
```

Launch the application:

```bash
streamlit run app.py
```

## Dataset
The initial dataset contains sample traffic records. It can be extended using verified real-world traffic observations.
